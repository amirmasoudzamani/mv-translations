## English
A WordPress plugin for managing song translations with singer taxonomy, transliteration support, video links, and frontend user submissions.

## ✨ Features

- Create and manage song translations using a Custom Post Type
- Organize translations by singers using a custom taxonomy
- Store additional translation information:
  - Transliteration availability
  - Video URL
- Frontend form for user-submitted translations
- User dashboard for managing submitted translations
- Edit and delete submitted translations
- Translation approval workflow
- Display translation status (Pending, Approved, etc.)
- Lightweight and built following WordPress coding standards

---

## 🚀 Usage

After activating the plugin:

1. Create translations from the **Translations** menu.
2. Assign one or more singers to each translation.
3. Fill in the available translation options:
   - Has Transliteration
   - Video URL
4. Allow registered users to submit their own translations from the frontend.
5. Review and approve submitted translations from the WordPress admin panel.

---

## Translation Fields

Each translation includes the following additional fields:

- Has Transliteration (Yes / No)
- Video URL

---

## Singer Taxonomy

The plugin includes a custom taxonomy for organizing translations by singer.

---

## Frontend Features

Registered users can:

- Submit new translations
- View all submitted translations
- Edit their own translations
- Delete submitted translations
- View translation status

Example statuses:

- Pending Review
- Published
- Draft

---

## Installation

1. Download or clone this repository.
2. Upload the plugin folder to:

```text
wp-content/plugins/
```

3. Activate the plugin from the WordPress admin panel.

# فارسی

# معرفی

MV Translations یک افزونه وردپرس برای مدیریت ترجمه آهنگ است که امکان دسته‌بندی ترجمه‌ها بر اساس خواننده، ثبت اطلاعات تکمیلی، ارسال ترجمه توسط کاربران و مدیریت فرآیند بررسی و تأیید ترجمه‌ها را فراهم می‌کند.

## ✨ امکانات

- مدیریت ترجمه‌ها با استفاده از Custom Post Type
- دسته‌بندی ترجمه‌ها بر اساس خواننده با استفاده از Taxonomy اختصاصی
- ثبت اطلاعات تکمیلی برای هر ترجمه:
  - وجود آوانویسی
  - آدرس ویدیو
- فرم ارسال ترجمه توسط کاربران در فرانت‌اند
- پنل مدیریت ترجمه‌های ارسال‌شده توسط کاربران
- امکان ویرایش و حذف ترجمه‌های ثبت‌شده
- سیستم بررسی و تأیید ترجمه‌ها
- نمایش وضعیت هر ترجمه
- توسعه‌یافته بر اساس استانداردهای وردپرس

---

## 🚀 نحوه استفاده

پس از فعال‌سازی افزونه:

1. ترجمه‌های جدید را از بخش **Translations** ایجاد کنید.
2. برای هر ترجمه یک یا چند خواننده انتخاب کنید.
3. اطلاعات تکمیلی را وارد کنید:
   - دارای آوانویسی است؟
   - آدرس ویدیو
4. کاربران ثبت‌نام‌شده می‌توانند از طریق فرم فرانت‌اند ترجمه‌های خود را ارسال کنند.
5. ترجمه‌های ارسال‌شده را از پنل مدیریت بررسی و تأیید کنید.

---

## اطلاعات هر ترجمه

برای هر ترجمه می‌توان اطلاعات زیر را ثبت کرد:

- دارای آوانویسی است؟ (بله / خیر)
- آدرس ویدیو

---

## دسته‌بندی خوانندگان

این افزونه دارای Taxonomy اختصاصی برای مدیریت و دسته‌بندی ترجمه‌ها بر اساس خواننده است.

---

## امکانات بخش کاربران

کاربران ثبت‌نام‌شده می‌توانند:

- ارسال ترجمه جدید
- مشاهده ترجمه‌های ثبت‌شده
- ویرایش ترجمه‌های خود
- حذف ترجمه‌ها
- مشاهده وضعیت هر ترجمه

نمونه وضعیت‌ها:

- در حال بررسی
- منتشر شده
- پیش‌نویس
